## Copy files from container
```
sudo sh sh/copy_files_from_container.sh -i [container_id]
```
This command will copy next directories and files:
- dist/
- node_modules/
- package-lock.json

## RTS: фреймы и очередь команд

Все объекты карты (`game.entities`) и события (`game.events`) находятся во Vuex (`src/store/game.js`).
Каждый вызов `game/tick` пересчитывает один кадр через `advanceFrame` (`src/game/frame.js`):
применяет текущий приказ каждого юнита, двигает персонажей, выполняет атаки и удаляет завершённые события.
Компоненты `GameField`, `MapUnit`, `MapBuilding` и `MapGround` отображают актуальное состояние стора.

У каждого события есть `id`, `unitId`, `type` и `nextId` — ссылка на следующий приказ этого юнита.
Первое событие в очереди юнита активно, остальные ждут его завершения. После достижения точки
маршрут продолжается без паузы; после уничтожения цели выполняется следующая команда.

**Управление:** ЛКМ — выделить объект; ПКМ по земле — идти; ПКМ по врагу — атаковать;
**Shift + ПКМ** — добавить команду в конец очереди. ПКМ без Shift заменяет все текущие приказы.
Маршрут выделенного персонажа показан пунктиром, последующие точки — кругами.

Запуск (из папки `vue`):

```bash
npm install
npm run dev
```

Проверка игровой логики: `npm test`.
