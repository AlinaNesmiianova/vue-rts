# RTS на Vue — группы, сценарии и игровой цикл

Запуск в PowerShell (Windows):

```powershell
cd vue
npm.cmd install
npm.cmd run dev
```

Тесты: `npm.cmd test` (запускать из папки `vue`).

В игре есть три готовых сценария: **Дуэль** (2 группы), **Три фронта** (3 группы), **Четыре стороны** (4 группы).
Для каждой группы заданы собственные персонажи и здания. Все группы доступны для ручного управления.

**Управление:**
- ЛКМ — выделить бойца / здание любой группы.
- ПКМ на земле или объекте своей группы — переместить бойца.
- ПКМ на объекте другой группы — атаковать (бойцы могут атаковать любые другие группы).
- Shift + ПКМ — добавить команду в очередь после предыдущих.
- «Загрузить» — подготовить выбранный сценарий заново.
- «Запустить» — начать выполнение подготовленных очередей; «Пауза» / «Продолжить» — остановить / продолжить кадры.
- Пробел — пауза / продолжить (когда фокус не на кнопке или поле ввода).
- «Заново» — сбросить текущий сценарий в режим подготовки.
- WASD / стрелки — камера, Ctrl + колесо — масштаб.

В режиме **подготовки** или **паузы** можно раздать новые приказы, которые начнут исполняться после запуска.
Каждый готовый сценарий уже содержит цепочки атак для бойцов, поэтому его можно запустить без дополнительных команд.

## Устройство проекта

- `vue/src/game/groups.js` — группы, их имена и цвета. Функция `createGroups(count)` поддерживает произвольное число групп.
- `vue/src/game/scenarios.js` — готовые сценарии (расстановка, объекты и связанные очереди событий).
- `vue/src/game/events.js` — события `move` / `attack`, `nextId` для последовательного выполнения.
- `vue/src/game/frame.js` — чистый расчёт следующего кадра; `combat.js` — движение и атаки.
- `vue/src/game/result.js` — победитель определяется по оставшимся живым юнитам **и зданиям**. Если не осталось никого, ничья.
- `vue/src/store/game.js` — Vuex: карта, группы, сущности, события, текущий сценарий, состояние (`ready`, `running`, `paused`, `finished`), победитель и время.
- `vue/src/components/pages/GamePage.vue` — панель сценариев, пауза, счётчики групп и итог партии.
- `vue/src/components/game/*` — отображение состояния, выделение и запрос действий через шину событий.

При уничтожении последнего объекта предпоследней группы партия автоматически завершается и останавливается; новые приказы после этого не исполняются. Перезапуск загружает свежую расстановку и очереди.
